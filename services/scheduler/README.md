# Scheduler Service

Handles scheduling operations for CounselConnect including:

- Hearing schedule recommendations
- Court agenda optimization
- Conflict detection
- Reminder notifications
- Absence tracking

**AI Control Model**: The scheduler may recommend scheduling options but must not independently confirm final hearing dates. See [Architecture Rules](../../docs/rules/01-architecture.md).

## Status

Not yet implemented. This service will be built in a future development phase.
